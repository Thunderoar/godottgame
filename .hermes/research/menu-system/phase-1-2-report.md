## 3. Deviations from the brief / spec

1. **SFX bus ownership is split.** The brief's item 2 asks `Sfx` to apply the `GameSettings` volumes,
   so `GameSettings` applies only the **Master** bus (plus window mode) and `Sfx` applies the **SFX**
   bus. `mute_all` reaches both: Master is muted by `GameSettings`, SFX by `Sfx`'s `changed` listener
   (also applied in `Sfx._ready`, so a mute set before `Sfx` existed still lands). Zero volume mutes
   the bus instead of asking for `-inf` dB; `-60 dB` is the arithmetic floor.
2. **Not every key is "applied" by `GameSettings`.** `ui_scale`, `touch_controls`, `screen_shake` and
   `auto_pause_on_focus_loss` are stored, validated, persisted and announced through `changed(key)`,
   but their consumers (HUD root scaling, touch visibility, `FollowCamera.shake`, pause-on-focus-loss)
   are phases 3–5. No consumer exists yet, so applying them here would mean reaching into nodes that
   are not created.
3. **`ask(..., danger: bool = false)`** is written with an explicit type: the project rule is typed
   signatures everywhere, and `danger := false` is not valid parameter syntax.
4. **`ConfirmDialog` extends `ModalBase` but overrides `close_panel()`** to cancel instead of running
   the base's `_clear_content()`, which would free the dialog's own widgets and make reuse
   impossible. It also hides the inherited header `Close` button (two cancel affordances would be
   confusing) and re-emits the base `closed` signal after `confirmed`/`cancelled` for opener cleanup.
   It does not `await` `open_panel()`'s process frame, so `ask()` works on the title and under pause.
5. **`Game._run_active()`** is a new private helper rather than an inline condition, because the guard
   reads better and phase 5 can reuse it. It also excludes the frames between worlds (world already
   freed / not yet built), where a save would be useless rather than harmful.
6. **Fullscreen apply is skipped when `DisplayServer.get_name() == "headless"`**, so the gate cannot
   log DisplayServer errors into the stdout it greps. The setting still saves/loads; a real window
   applies it.
7. **Defaults chosen:** volumes 100/100 (leaves today's audible level unchanged — buses at 0 dB, the
   players keep their `-7 dB`), `mute_all` false, `fullscreen` false, `ui_scale` 100,
   `touch_controls` `"always"` (matches current always-visible behaviour, per spec), `screen_shake`
   true, `auto_pause_on_focus_loss` true.
8. **Temporary tooling:** two throwaway `tools/p12_probe*.gd`/`.tscn` pairs were used for the runtime
   checks above and deleted; the shipped tree has no new `.tscn`. They were needed because the suite
   scene cannot be repurposed for a one-off probe without editing it.
